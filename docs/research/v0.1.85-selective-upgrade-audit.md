## 本地额外修复与保留项

输入光标镜像使用实际排版；电脑菜单不用系统白色下拉；启动加载前后控件不跳动、草稿不丢；
“询问”和电脑选择按内容宽度紧凑排列。飞书旧路径仅在 realpath 确认是同一随包桥接程序时迁移，
不接管其他同名 MCP。搜索图片展示/放大、PDF/HTML/文本预览和 HTML 脚本隔离保留。

这些行为已在前面的本地构建及临时 Electron fixture 验证，不代表真实联网搜索质量或 Mac 权限已测。
本轮补齐的手动更新由 IPC/行为测试、实际 React 渲染与 TypeScript 检查验证；没有生成安装器。
