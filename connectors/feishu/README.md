# 团团飞书连接器

Windows 本机桌面的独立连接器。无新增第三方依赖,不修改内核,旧云端飞书渠道保持不变。

## 使用

当前公共界面已升级为一键连接:选择 bot,点击连接,缺少 CLI/Node 时自动校验下载到团团私有目录,随后自动打开官方应用配置与用户授权页面。无需手动选择程序、复制密钥、发送配对码或点击授权完成。下列手工步骤是旧预览流程的历史说明,不作为新版操作要求;最新验收见 `docs/tuantuan/WINDOWS-CODEX-HANDOFF.md`。

1. 安装官方 `@larksuite/cli` **1.0.93**,在本机完成 `lark-cli config init`。应用需要机器人能力、长连接消息订阅、私聊接收及机器人发送权限,并完成平台要求的发布/审批。应用密钥只交给官方 CLI。
2. 打开团团 `Plugins / Connected Apps / 飞书`,选择安装目录里的原生 `lark-cli.exe`,不是 npm 的 `.cmd` 包装器。
3. 个人办公授权:发起用户授权,在官方页面确认后点“完成授权并检查”。办公工具另需选择本机 Node.js 24+ 的 `node.exe`。
4. IM:选择一个 bot,生成配对码,由机主私聊飞书机器人发送配对码,在桌面原生窗口确认身份;再连接。首次连接会征求同意创建并激活“飞书任务”。
5. 旧版办公工具启用后需每次原生确认。2026-09-08 用户已变更要求，当前 Windows 产品按下节自动执行策略运行。

初始五项工具:读取文档、创建纯文本文档、查询时间范围内的日程、创建日程、以用户身份发送纯文本私信。日程创建沿用 CLI 的视频会议及提前五分钟提醒默认值,工具描述有提示。工具不能执行任意 CLI 指令,不自动追加 `--yes`。

MCP 是工作区级,并非按选中的 IM bot 隔离。当前 Windows 宿主默认允许五项白名单办公工具使用已授权账号执行，不再逐次弹窗，UI 明示该范围。不信任 Agent 自报的 bot 身份，CLI/Agent 在机主权限下运行，本插件不是操作系统沙箱。

自动策略仅由宿主注入 `authorizeTool`，renderer、MCP 参数及存储配置不能控制该回调。每次调用仍校验工具与参数、桥接能力、当前账号/应用、本机窗口和连接生命周期；断开立即停用。不修改内核审批模式，不增加 CLI `--yes`，不绕过飞书平台或企业权限。连接器作为独立库未指定策略时保留原生确认回退，旧模式回归测试仍保留；当前 Windows 产品始终提供自动策略。

## 生命周期与数据

### 原应用已删除或停用

CLI 确认原应用不可用（精确 `20069 / invalid_client` 或固定版本对应身份诊断）后，显示“重新创建并授权”，不再误导用户重复旧应用 OAuth。用户选择后在团团私有 `recovery/<随机标识>/context` 创建独立配置，由官方浏览器完成新应用配置和授权。

成功前主绑定与旧配置文件保留；中断后保存候选应用进度，继续同一次流程，已创建应用不重复创建。用户明确选择重新创建并完成官方授权后，连接器复核新应用和 OAuth 用户并自动提交新绑定（不同应用的用户 ID 可能不同），不再追加“替换应用”弹窗。办公工具使用上述宿主策略。临时网络错误、普通用户授权不足不会自动替换应用。

健康重连若身份及全部所需 scope 已在线验证通过，复用现有授权；未验证或缺 scope 时仍需要官方授权，不以缓存单独认定成功。

连接时即时显示进度，进行中每 400ms 读取本机阶段（空闲时 2 秒）；分别显示配置页准备、浏览器配置、应用验证、授权页准备和授权等待。等待较久时显示当前阶段等待秒数，不伪造百分比。一次检查中已取得的同应用权限预检查可直接用于紧接着的 OAuth，不跨操作缓存。

预览包迁移到安装版时，旧 MCP 脚本路径会不同。仅当旧注册具有两个固定桥接环境变量名，且旧 `resources/tuantuan-feishu/` 下的 `mcp.mjs` 和 `tools.mjs` 与当前发行内容逐字节一致、没有路径链接时，才迁移为当前包注册并重新测试。旧脚本不被加载或执行；文件缺失、修改过或第三方同名配置不自动覆盖。

- 用户选择的程序路径、应用标识、配对用户、任务标识及最近 1000 个消息 ID 写入桌面系统加密存储;不保存消息正文或 CLI token。
- CLI 自己负责凭据、刷新及本地事件总线。断开只停止本插件消费者和工具入口,不执行全局 event stop、CLI logout 或撤销其他应用。
- 工具桥接短期令牌只允许通过宿主策略的白名单工具调用,不是内核 owner capability;停用立即失效。内核 MCP 配置包含该短期令牌,重启后旧值不可用。
- 成功连接后保存自动恢复选择，客户端下次启动自动恢复 IM/MCP；主动断开则取消恢复。旧版没有保存此选择，升级后需连接一次，后续启动自动恢复。关闭客户端仍停止进程，不承诺离线工作或补发离线期间的消息。
- 自动恢复仅复用经过验证的完整授权，不自动创建应用或弹浏览器授权；缺权限、授权过期、身份变化时显示错误并保留原绑定，待用户重试。
- 断开不能撤回已送出的飞书写操作或取消已提交的内核任务。失败或超时不承诺稍后补发;不自动重试结果未知的写请求。
- CLI 背压和离线消息不保证无损。仅配对机主的文本私聊可投递,群聊、陌生人和非文本消息不执行任务。

## 验证

```sh
pnpm --filter @tuantuan/feishu-connector test
node --test electron/tuantuan-feishu.node-test.mjs
pnpm exec vitest run src/tuantuan/feishu src/components/PluginsPanel.test.ts
node --experimental-strip-types connectors/feishu/fixture-smoke.mjs
```

fixture 使用官方隔离 launcher,真实内核、假引擎和假飞书传输,验证 IM 关联、去重以及真实 MCP 注册/探测/审批/断开。禁止对演示/试用服务运行验证。

Windows 安装包在隔离构建目录生成,不得覆盖当前服务器试用所用的 `dist`/`dist-server`。编译、模拟测试和 Wine 离线检查不能替代真实 Windows 安装、官方账号授权、IM 收发及四引擎工具审批验收。
